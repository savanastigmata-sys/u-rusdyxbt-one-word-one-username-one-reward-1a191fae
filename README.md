One word, one username, one reward — a deterministic, standard-library-only Python program that writes the entrant's own make.fun username, `savana`, as a single word to `entry.txt`. One word, no explanation, no links, no pitch: 6 characters, well inside the 1–30 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
